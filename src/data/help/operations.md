# ILCE-9 工具 v1.9.1 操作说明

1.9.1 的 V8 前置检查同时接受标准菜单库及完整 SHA256 为 `07ffd8df517022d9e661240082170ea013023fdeb76156b5510c702bc19fed9e` 的已知段长度变体。界面明确显示「标准版」或「已知段长度变体（兼容）」。其余 R15NH 文件、CFG、LUT 校验保留。1.9.0 因此变体阻断的机身可直接换用新程序，在 V8 页重新读取状态并部署，无需为此重刷 R15NH。保留原 sessions 和回滚来源；本次不更改 R15NH 差分修补、FF01 写入或 V8 载荷。

本版基于已发行 v1.8.2 原生 Windows 界面与 USB 通信，适用于 Sony ILCE-9 固件 6.00。保留原 Fn 功能、电子快门引闪、5 GHz WiFi 和强制回退页；创意外观 LUT 更新为 R15NH，新增单独的 V8 悬浮菜单页，共六页。无需安装 Linux 或另换通信方式。

旧 R15NH / V8 包及原 FF01 路径已有用户实机记录，本版安装器集成流程待实机验收；分别记录本版备份、写入、回读、冷启动、实际拍摄与回滚结果。离线检查只证明资源和软件检查通过。

## 1. 连接与工作目录

使用完整交付文件夹，启动 ILCE-9_Slog_Project.exe。相机 USB 设为「大容量存储」，只连接这一台机身；使用可靠数据线和充足电量。沿用 v1.8.2 的原生 USB 驱动准备和「连接并检查 / 重试」流程，驱动详细步骤见 README 的原生连接说明。不要同时运行官方更新器、旧工具或其他相机控制程序。

Fn 页的「连接并检查」用于原 Fn / PP 操作。R15NH、V8、引闪、WiFi 和官方回退入口各自建立所需原生服务连接；运行需要机身的部署动作前，窗口先关闭已打开的 Fn 会话。检查资源、识别备份和修补备份均为离线操作，不连接相机，也不关闭已打开的 Fn 连接。不用先在 Fn 页连接才能使用新页。

日志显示 sessions 的完整路径。R15NH 操作至少准备 3 GiB 可用磁盘空间；完整分区备份、配套配置、回读与日志会占用较多空间。保留所有完整或部分材料，不把另一台机身备份混入。

写入前明确确认；处理中所有机身动作禁用，关闭窗口会要求等待当前任务结束，不强杀写入。结果未知时不自动重发。任务完成后旧页按原状态恢复操作，新页可继续读取核对。

## 2. R15NH 创意外观 LUT

R15NH 提供 27 款内置 LUT、16 个自定义槽位及 NAME / HELP 功能。它沿用成熟 R12 的「读取 → 识别 → 修补 → 写入」流程，内置的是差分补丁，不分发完整分区镜像。补丁只作用于你自己机身的已完整读取并识别的备份，在本地生成候选；写入使用 FF01 完整 nflasha15（300 MiB）分区流程，不通过 /usr 逐个替换文件。

支持完整识别的原厂、R8、R9、R9.1、R10、R11、R12 来源分区；未知、损坏或混合状态拒绝。四份 CFG 和两份 LUT 配置原样保留，原始完整分区、配置及会话成对保存和回滚。备份代表备份时状态，不保证是原厂。

可先点「辅助：检查内置差分补丁（离线）」，它不连接相机。六个步骤如下：

1. 「① 初始备份」：完整读取 300 MiB 分区、四份 CFG 及两份 LUT 表，保存同机身份、摘要和原始会话。只有完整可恢复材料才可用于后续动作；部分读取保留记录，但不能作为已完成备份。
2. 「② 识别备份版本（离线）」：核对同一备份来源并保存识别证据，不读取相机。不支持的来源不会解锁修补。
3. 「③ 从备份修补 R15NH（离线）」：使用内置差分补丁，基于这份已识别备份生成 prepared 候选及摘要证据。原始备份保留，不能把其他会话的候选或证据混入。
4. 「④ 写入 R15NH 整分区」：先验证本地已修补候选，才连接相机重新完整读取现场并与备份比对；通过后单次写入、完整回读。写入按钮不会现场自动生成目标或绕过识别和修补。不得拔线、断电或重复点击。完成后正常关机、完整断电并冷启动，核对原生创意外观、NAME / HELP、实际照片及再次冷启动。
5. 「⑤ 写入 4:3 保存参数」：保留原生参数写入，与整分区 LUT 部署分别执行。
6. 「⑥ 从原始会话回退 R15NH」：使用原始完整分区及配套配置成对回滚，详见恢复章节。

「当前工作备份 / 修补会话」与「原始回滚来源」分开。退出程序后可重新选择已有完整备份，窗口在后台审核备份、识别和修补证据，通过对应步骤后才解锁按钮；仅填写路径不能启用写入。识别、修补与候选都属于同一原始备份会话。后台审核不访问相机，后端在每步仍重新验证证据。

## 3. 先 R15NH、冷重启并核对，再单独部署 V8

V8 部署必须先有正确的 R15NH。V8 使用 nflasha10 内的 /etc、/tmp 和预加载入口，先写入并回读载荷，最后切换 preload。它不会替你补装 R15NH，也不以旧成功日志代替本次现场验证。

1. 完成 R15NH 部署、冷启动及状态核对后，打开「悬浮菜单 · V8」。
2. 点「① 检查内置 V8（离线）」，检查固定发布资源。
3. 点「② 读取 V8 与 R15NH 状态」，核对依赖和当前文件状态；这份只读会话不代替 V8 部署备份。
4. 点「③ 部署 V8（须先有 R15NH）」。后端每次重新检查现场 R15NH 和来源；不匹配即停止，不写入试探。
5. 保留本次原始部署会话，冷启动后按下一节加载菜单，分别验收显示、按键和实际效果。

V8 可直接检查或读取状态，界面提示先安装 R15NH，最终依赖条件由后端本次检查决定。R15NH 则严格经过备份、识别和离线修补才能写入。两个模块回滚来源分别保存，不能互用。

## 4. 冷启动加载与触摸限制

按已有用户测试记录，冷启动后 10 秒内先进入原生 MENU；如出现 NTSC 确认框，先确认。停留一段时间再回到 HUD，该停留时间尚未量化，不提供未经验证的秒数。然后触摸释放，加载悬浮菜单。不能据此推定 NTSC 制式本身是加载必要条件。

按键唤出时先放开按键，再同时按住 MENU + AEL 约 0.6 秒。原生 MENU 前置步骤是现有操作记录，不是已证明的根因修复；正常冷启动能否稳定加载仍须本版实测。

触摸的 6 行只是普通控件边界。FTP 等页面可选项多于 6，使用不同子页机制，其他页面的触摸覆盖尚未证实。已有记录明确 R15 创意外观二级菜单触摸不生效，本版没有声称修好。按页面支持的物理按键操作，并记录具体页面及动作。

## 5. 正常回滚与中断恢复

每页「同机原始回滚来源」选择对应模块原始会话绝对路径。R15NH 使用原始完整备份会话，识别、修补和写入均引用该备份；V8 使用最初部署会话。窗口保留原始来源，后续识别、修补或回滚不改为新快照，部分读取失败也不会覆盖旧完整备份来源。

V8 已激活时再次部署，本次会话不能代替最初安装会话用于卸载，窗口会保留原来源并提示。来源本来已为 R15NH 的重装同样保留此前原始备份，不改成当前 R15NH 快照。

已部署 V8 时，先回退 V8、冷重启并核对，再回退 R15NH。R15NH 的「⑥ 从原始会话回退 R15NH」通过 FF01 写回完整 nflasha15，并成对恢复原配置及 LUT 表后核对，恢复的是备份时状态。

V8 的「④ 从原始会话回退 V8」只恢复原 preload，保留已部署载荷，不删除载荷或恢复其他原文件。中断后先读现场、核对原始会话，再使用「恢复 V8 中断事务」，明确确认恢复原 preload；此操作可能覆盖之后的 preload 修改，不声称采用三态核对算法。

错误发生时保留失败记录和所有完整或部分材料。只有后端明确报告可恢复原始会话时，窗口才更新回滚来源；单有失败记录路径不能证明可回滚。不直接重发写入，不删除日志或猜测备份。

## 6. 原有四页及官方更新器

Fn 页仍保留 77 项功能、原「连接并检查 / 重试」和备份恢复。PP 为 0x3A，S-Log 显示辅助为 0x36；多数其他功能未经实机验证，已知异常值禁止写入。引闪、WiFi 和官方回退入口沿用原流程及恢复按钮，电子单张旧反馈不能推定连拍每张引闪或硬件安全。

强制回退只改 /setting/updater/dat4 两字节，开放官方更新器入口；成功不等于已降级或恢复全部分区。运行 Sony 官方更新器前结束本工具任务并关闭窗口，按 README 的原生驱动还原说明将相机恢复为 Windows 大容量存储驱动，再使用对应官方指南。不要让两套程序同时占用机身。

# R15NH 与 V8 相机操作

本页依据 R15 NAME HELP 发布说明、其 TEST_GUIDE，以及 V7.1 三页菜单说明整理。V8 继续使用相同滤镜和声音交互，仅增加已交付的原生 MENU 触控。先执行本版使用手册的冷启动 MENU 前置步骤。

## R15NH 原生创意外观

在拍摄辅助第 14 页进入「创意外观」，该页同时保留图片配置文件和伽玛显示辅助入口。打开「外观模式」列表，选择并确认预设；27 款内置外观和 16 个自定义槽位沿用原四页布局。参数调节及第四页保存、导入继续使用物理按键。当前 V8 在这套创意外观二级菜单中触摸不生效。

NAME 是名称显示行为：已导入槽显示 A9P 内部名称，去掉「Custom n／自定义 n」前缀；空槽仍显示编号。列表中的长名称可以省略显示，内部名称没有因此缩短。

HELP：保持「外观模式」列表打开，将光标移到要查看的项，按删除／帮助键查看当前高亮项的完整名称。确认或 MENU 关闭弹窗；查看帮助不应用该项，也不触发保存。支持关闭项、内置项及已导入自定义项，空自定义槽不弹窗。

自定义 LUT 沿用 A9P V2 格式，2756 字节，名称最多 64 字节。将合法文件按槽号放在卡槽 1 存储卡根目录下的 PRIVATE/A9FL/LUT1.A9P 至 LUT16.A9P，通过第四页的导入操作读取；导入会更新对应编号，不把普通 .cube 文件直接当 A9P 使用。已有预设无需因 NAME HELP 更新而重新导入。调整后使用原保存操作，再退出重入及冷重启核对名称、参数和实际色彩。

## V8 三页悬浮菜单

加载后先松开按键，再按住 MENU＋AEL 约 0.6 秒打开。Previous／Next 双向循环三页；Close 关闭。打开后 60 秒关闭，翻页不重置倒计时。

第一页是声音，第二页选择滤镜并提供 Save／Cancel，第三页只读显示已经 Save 应用的滤镜名称和 16 项后端参数。第二页只选候选而未 Save 时，第三页继续显示之前已保存的滤镜。要调整参数，回原生创意外观页面；第三页不是参数编辑器。进入第三页时读取失败、后端忙或未保存会显示 unavailable；Off 表示参数未生效。

声音依次为 OFF、SINGLE、LOOPL、LOOPH、LOOPSH、AUTO。Preview 试听当前有效档。缺素材的手动档跳过；AUTO 缺少所需素材或查询失败显示 unavailable，不自动替换成其他档。AUTO 按已知释放模式选择声音：L→LOOPL，M→LOOPH，Hi／Hi+→LOOPSH，其他已知有效照片模式→SINGLE。这是按键音策略，不等于与每次实际曝光同步。此前 AUTO 间歇 unavailable 和声音间断的原因尚未查明，本安装器没有修改此行为。

需要导入已发布的四槽声音包时，将合法 WPS.A9W 放到卡槽 1 的 PRIVATE/A9FL/WPS.A9W；声音页先设 OFF，再点 Import WPS，等待 Saved; restart to test 后冷重启，重新执行 MENU 前置步骤。导入后保存到机内，移卡仍可使用；旧三槽包不会提供 LOOPSH。机身音频信号沿用「开：除电子快门以外」。WPS4 在 RAM 中借用 Wi-Fi 关闭提示音绑定，原生 Wi-Fi 关闭提示也可能播放这段声音。部署器本身不导入或改写声音记录。
