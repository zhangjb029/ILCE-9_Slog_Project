# A9 多品牌 A9P 色表库 · 2026-11-21

本包包含 **227个 A9P V2**：富士70、宾得59、松下57、尼康5、GlassMeter胶片模拟30，以及徕卡／ARRI／RED／电影胶片等社区跨品牌映射6个。数量包含来源基底和调色变体，不等于227种独立的厂家原厂风格。所有文件均为从下载色表数值拟合得到，没有按名称编造配色。

**135个列为常规近似，92个列为高误差实验项。** 格式可导入与颜色拟合好坏是两个独立结论；尤其黑白和强烈偏色项可能明显偏离原始目标。先在 `index.html` 查看左上目标／右下拟合色卡，再按目录选用。

## 使用

1. 机身须已部署支持完整七位 `[-64,63]` 自定义表的 **R15**。本包是色表资源，不含固件镜像，也不执行刷机。R14不能作为本包七位数据的兼容基线。
2. 打开 `index.html` 搜索风格；`CATALOG.csv` 包含名称、来源、sRGB／AdobeRGB色差与等级。
3. 在 `SD_CARDS` 选择**一个**组。建议先选 `NORMAL_APPROXIMATION_`，`EXPERIMENTAL_HIGH_ERROR_` 单独存放高误差项。每组最多16个，`SLOTS.csv` 列出将覆盖的自定义槽。
4. 将卡槽1存储卡上 `PRIVATE/A9FL` 中以前用于导入的 `LUT1.A9P`～`LUT16.A9P` 备份并移到电脑，防止旧文件混入本次导入；再将所选组的 `PRIVATE` 文件夹复制到卡根目录。
5. 机身“创意外观”第4页选择“导入”。名称会显示为“自定义 n + 文件内名称”。选择对应槽观察效果；普通菜单“保存”仍按R15既有流程使用。

同一批只有16个自定义槽。电脑库可以保留全部227个，分批换用。导入只更新有对应文件编号的槽；卡组会覆盖该组 `SLOTS.csv` 列出的编号。可从 `A9P` 任选文件另存为 `LUT1.A9P`～`LUT16.A9P`，不改变其内部内容。

## 来源与真实性

- **富士70：** 官方LUT映射去重后49个、abpy社区Camera Profile色表11个、从官方资源转换的社区ProPhoto版本10个。已收集30个官方ZIP下载（含旧版／重发包）；同一映射在多个型号包中出现时保留来源，转换目录去重。F-Log、F-Log2、F-Log2C和版本差异仍可能形成多个适配条目。
- **宾得59：** 来自 Viyerelu23333/custom-image-luts 的社区拟合；以K-1 Natural JPEG为输入的相对风格，应用到A9原厂基底。不是理光／宾得官方导出色表。保留18种基础模式及调色变体；V-Log虚拟机身版本作为原始资源保留，未重复计入同系列。
- **松下57：** VariCam官方E-E完整范围库35个，加官方公开分发的18个创作者下载包中的22个映射变体。没有用E-L legal-range版本替代E-E。
- **尼康5：** 官方N-Log技术LUT以及RED合作外观 ACHROMIC、FILM BIAS、BLEACH BYPASS、OFFSET。另已收集185个NP3及1个NCP原件，因基础渲染及部分新调色块尚无完整可验证映射，**这186个没有伪装成已转换A9P**，见 `provenance/NIKON_PRIVATE_PENDING.json`。
- **胶片30：** GlassMeter／Glass Works 原创胶片解释，涵盖富士、柯达、伊尔福和CineStill名称；不是这些胶片厂商发布的官方LUT。
- **其他6：** 社区V-Log跨品牌变换，涉及徕卡、ARRI、RED和电影印片模拟，不是相关品牌认证的A9固件功能。

下载来源、原件SHA256、Git blob身份、原包内路径及去重原因均在 `provenance`。原始下载保存在工作目录 `sources`；下载与网页失败也保留记录。没有绕过登录或付费。

## 拟合与限制

采用R15实验性Y／压缩色度模型，对两张1280字节原生源属性分别拟合，完整使用七位范围，保持尾65字节和亮度单调。使用冻结的训练／验证／测试划分，测试集每张表17,343个点，不参与参数选择；200步感知细化。A9P含名称、ILCE-9／6.00与原厂表身份、双表及CRC32。

显示域色表按其声明色域和曲线转换。Log色表先把A9名义输出RGB反解为线性代理，再转换到F-Gamut／F-Gamut C／V-Gamut／BT.2020并编码对应Log；不包含A9原厂色调曲线的逆标定，也不建立跨品牌传感器等价。富士和部分创作者资料没有明确输出EOTF，本包将其BT.709输出解释为gamma2.4；这是公开记录的工程假设。ProPhoto社区版使用其说明的gamma1.8及D50白点适配。

这些是**给定参考变换相对于离线模型的拟合误差，不是相机实拍测色，不证明与富士／尼康／宾得机身颜色完全相同**。颗粒、锐化、清晰度、空间光晕等不能由静态色表完整承载。

工程分级取两张表中较差者：A为均值<2且P95<5；B为均值<4且P95<10；其余C均为实验。分级不是厂商认证或视觉无差别承诺。部分黑白仍有残余色度；部分VariCam强偏色项受到七位边界限制，误差很大，不能称成功复刻。

## 校验与目录

- `A9P/`：227个原件，按来源分组、按来源原始文件名称命名，扩展名为`.A9P`。
- `SD_CARDS/`：23组16槽以内的卡目录，常规与实验分开。
- `charts/ALL_overview.jpg`：255项总览；`EXISTING_28_overview.jpg`为现有28项，`IMPORTED_227_overview.jpg`为新增227项，各品牌与逐项色卡也在此。
- `CATALOG.csv`、`GROUP_METRICS.csv`、`REPORT.json`：总体与逐项色差、参数边界和来源。
- `SHA256SUMS.json`：逐文件完整性。

所有227个文件都通过Python严格重读及**R15实际 `a9_pack_decode` C导入解析器**的本机编译交叉验证，并核对每个卡组的编号与文件哈希。未运行QEMU，未连接相机，未改任何已有固件；机身实际导入与拍摄效果仍由用户验收。

## 文件夹交付与浏览

直接使用本文件夹，无需解压。双击 `index.html`，页面可离线查看、搜索和筛选**255项**：现有**28个画面预设**（27内置＋原厂关闭）和**227个新增A9P**。现有项按R14 FIX／R15菜单顺序排列，不把两个极端自定义测试槽计入28项。

全部预览使用既有宣传图的标准24色、同一原厂输出基线。现有项每格左上为原厂、右下为当前外观；新增项左上为来源LUT目标、右下为A9拟合。现有28项使用冻结的生产默认参数表，输出RGB与原有R15宣传图逐项核对一致。`GALLERY.json`保存预览浮点RGB；`REPORT.json`仍保留拟合时的原始测试色卡和独立测试指标，二者采样基线不同。

`A9P`库文件按**来源原始文件名**命名，例如 `cinestill-400d.A9P`；没有重新编码、修改内部名称或改变CRC与色表。页面同时列出来源名称和机身内嵌名称。相同风格的输入Log、版本或厂商目标变体保留原始名称差异。

`SD_CARDS`里的文件仍按机身导入协议命名为 `LUT1.A9P`～`LUT16.A9P`。各组新增的`SOURCE_NAMES.csv`与总表`SD_SLOT_MAP.csv`列出来源名称、机身名称与库路径；`SLOTS.csv`保留原有编号和机身名称对照。自行选取库文件时，将副本改成所需LUT编号再放进卡槽1的`PRIVATE/A9FL`；单纯把来源文件名放入该目录不会被现有导入器识别。

展开的复现目录位于交付文件夹旁的 `A9_MULTI_BRAND_REPRODUCTION_20261121`，无需压缩包；入口见 `REPRODUCE.zh-CN.md`。历史ZIP不属于本次文件夹交付，也未更新。
