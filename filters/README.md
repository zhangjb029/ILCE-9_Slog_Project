# A9 R15NH · 227 个 A9P 滤镜

本目录提供 227 个 A9P V2 原件，文件字节沿用既有离线验证库。富士 70、宾得 59、松下 57、尼康 5、GlassMeter 胶片解释 30、其他社区映射 6。数量包含不同输入基底和调色变体；不是 227 种独立原厂风格。

完整离线浏览页、色卡和 23 组 SD 卡目录请下载 [v1.9.0 Release](https://github.com/zhangjb029/ILCE-9_Slog_Project/releases/tag/v1.9.0) 的 `A9_A9P_227_FILTERS.zip`。直接拍照试用优先看 [照片推荐 16 槽](PHOTO_RECOMMENDED_16/README.zh-CN.md)，该组同时提供可复制的 `SD_CARD/PRIVATE`。

先部署 R15NH。将所需文件的副本改名为 LUT1.A9P 至 LUT16.A9P，放到卡槽 1 根目录的 PRIVATE/A9FL，在创意外观第 4 页导入；先备份旧卡内文件，勿混入不同组。每次只有 16 个自定义槽，库原件请留在电脑上。

135 个为常规近似，92 个为高误差实验项，指标见 [CATALOG.csv](CATALOG.csv)。Log 输入、ProPhoto 及 Pentax Natural 来源各有基底要求，拟合等级不能证明适合所有照片。名称帮助、保存及导入步骤见项目主手册。

来源许可不统一。宾得社区及 abpy 资源保留 CC BY-NC-SA 4.0；GlassMeter 来源为 CC BY 4.0，署名“Film simulations from GlassMeter by Glass Works (glass-works.ai)”。官方及其他资源保留原厂或作者条款，详见 [source_docs](provenance/source_docs) 及完整包 README。本项目不覆盖来源许可。

自己制作滤镜请看 [LUT 拟合与 A9P 详解](../docs/authoring/R15_V8_LUT拟合与A9P制作详解.md) 和 [离线代码](../tools/media/README.md)。教程附可复现示例、误差评估、双表导出及写卡路径，既有 227 个 A9P 原件不改动。
