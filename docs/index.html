Enable Picture Profile and S-Log Display Assist on the Sony A9

Applies to the original ILCE-9 running firmware 6.00. About 30 minutes, no Python, no command line.

Read this first

  • This tool changes camera parameters, not firmware. If something goes wrong you can restore from the backup it takes.
  • It works only on the ILCE-9 with firmware 6.00. Any other model or firmware is refused before anything is written.
  • It exposes 77 functions. Only Picture Profile and S-Log Display Assist have been confirmed working on real hardware. The other 75 have never been tested on a camera and may freeze or misbehave.
  • Pixel Shift Multi Shooting is known to hang after the first frame and require a battery pull. It is marked in red but still selectable.
  • Use at your own risk. This is not a Sony tool and Sony will not honour a warranty claim for damage it causes.

1. Before you start

Check three things:

  1. Your camera is an ILCE-9 — not an ILCE-9M2. The model is printed on the body.
  2. The firmware is 6.00. On the camera: MENU → Setup → Version.
  3. You have a USB data cable and a working Windows 10/11 PC.
Not on 6.00? Do not use this tool. Parameters live at different addresses in different firmware versions, and writing to the wrong one can damage the camera configuration. The program refuses, but check anyway.

Two pages worth opening now:

  • This tool's download page — the Releases page of this repository.
  • Zadig — a small free utility that installs the USB driver the camera needs.

2. Download

Download ILCE-9_Slog_Project.exe from Releases and put it somewhere you will find again — the Desktop is fine.

There is no installer and no uninstaller. It is a single exe. On first run it creates a sessions folder next to itself, where it keeps the pre-change backup of every write. Do not delete that folder — restoring depends on it.

Why does it need a folder? Before changing anything, the program saves the camera's complete parameter set into that folder. If a change goes wrong, or you change your mind, that is what puts it back.

3. Windows blocks the program

The first time you double-click it, Windows will probably show a blue box saying "Windows protected your PC".

Click More info, then Run anyway.

The reason is simple: the executable is not code-signed (a signing certificate costs several hundred dollars a year, which a hobby project does not have). Windows blocks every unsigned executable it has not seen before. It does not mean the file is malicious.

4. Antivirus warnings

Some antivirus products flag this program. Same reason: it talks to a USB device directly, which is also what certain malware does.

If that bothers you, the source is on GitHub — read it. Do not download this executable from anywhere else.

5. Install the driver (first time)

This is the step people get stuck on. Take it slowly.

5.1 Put the camera in Mass Storage mode

  1. Turn the camera off.
  2. Connect it to the PC with the USB cable.
  3. Turn it on.
  4. If the camera asks how to connect, choose Mass Storage.
  5. The memory card should appear in Windows. If it does not, try another cable or another USB port.

5.2 Replace the driver with Zadig

  1. Open Zadig (no installation needed).
  2. Choose Options → List All Devices.
  3. Pick your camera from the dropdown — it may show as Sony Digital Still Camera or similar.
  4. Make sure the target driver on the right says libusb-win32; use the arrows to change it if not.
  5. Click Install Driver or Replace Driver and wait for it to finish.
Do not pick the wrong device There may also be an entry such as USB Input Device with VID 054C and PID 0994. That is the camera's USB input interface, not the device this tool talks to. Replacing its driver will not break the camera, but it will break that input device on your PC.

5.3 The memory card disappears — that is expected

After the driver swap, Windows Explorer no longer shows the camera's card, and you may get a "you need to format this disk" popup.

The camera is fine. The new driver turns the camera from "a USB stick" into "a device a program can talk to directly", and Windows stops showing it as a disk. Do not format anything. Section 11 has the steps to put the original driver back.

6. Connect and check

Keep the camera in Mass Storage mode and run ILCE-9_Slog_Project.exe.

Click Connect and check in section ①. The program reads the model, reads the firmware version, confirms it is 6.00, saves a full backup of the current parameters, then switches the camera into service mode.

This takes a few tens of seconds; the log fills in as it goes. A good run looks like:

  • 已确认 ILCE-9 / 6.00，正在切换服务模式 — model confirmed, switching modes
  • 服务模式已认证，正在读取机身参数 — service mode authenticated, reading parameters
  • Then section ② fills in with model, firmware, and a serial fingerprint

The interface is in Chinese. The log lines above are what to look for.

7. Install the driver again (second device)

If step 6 stalls and the log shows "Service device not found", the camera has already switched into service mode but Windows has no driver for the device that just appeared.

That is normal: service mode is a separate USB device and needs its own driver install.

  1. Leave the camera plugged in exactly as it is.
  2. Open Zadig again, Options → List All Devices.
  3. A new Sony device is now in the list, usually with (Interface 1) or similar in the name.
  4. Install libusb-win32 for it too.
  5. Go back to the tool window and click 重试 (Retry).
The retry expires after one hour Come back too late and the program asks you to unplug the camera, return to Mass Storage mode and start over. Nothing has been written at this point, so restarting is safe.

8. Turn on the PP override, then restart

Once connected, section ② shows whether the PP override is on.

If it says 未开启 (off), click 开启 PP 放行. The program changes five bytes and saves.

Why restart? The parameters are written to storage; the camera only re-reads them on the next boot. The program will tell you to power-cycle — do that, and do not do anything else before restarting.

After the restart, run the program again and repeat the connect step. You do not need to install drivers a second time.

9. Write a function into an Fn slot

Section ③ shows two cards by default:

  • Picture Profile
  • SLog Display Assist (S-Log Display Assist)

Each card has a slot dropdown (Fn1 to Fn12). Pick a slot and click the write button.

For anything else, expand 全部功能（77 items, mostly untested）, pick a row, choose a slot, and click the write button.

After a successful write every write button in the window greys out. That is deliberate: one run of the program performs exactly one change, each with its own backup. To change another slot, close and reopen the program.

10. Check on the camera

Power-cycle the camera as prompted, then press Fn and look at the slot you wrote to.

"It appears in the menu" is not "it works" All twelve slots accept a write and the camera will display the entry — but an entry existing only means the entry exists.
  • Picture Profile and S-Log Display Assist: confirmed working on hardware, and they survive a restart.
  • The other 75: nobody has tried them. They may grey out, do nothing, or freeze the camera.
If one does nothing useful, section 11 puts it back.

11. Undo

11.1 Undo one change

  1. Open the program and connect.
  2. Section ④ lists every change you have made, with a timestamp and what it did.
  3. Select the row you want to undo.
  4. Click 从备份恢复到原状 (restore from backup).
  5. The program writes the old value back, saves, and asks you to power-cycle.
If you made several changes Each row's "original" value is the value before that particular write. Undoing the second change returns you to the state after the first one, not to the factory state. The list marks those rows so you can tell them apart.

11.2 Restore everything

恢复全部原厂 writes back every position this tool has touched, as it was before you first used it.

This overrides manual changes too It will also overwrite settings you changed by hand on the camera. Make sure that is what you want.

11.3 Give the camera back to Windows

  1. Close the program.
  2. Right-click Start → Device Manager.
  3. Find the camera under "libusb-win32 devices" or similar.
  4. Right-click → Uninstall device, and tick Delete the driver software for this device.
  5. Unplug and replug the USB cable.
  6. Windows reinstalls its own driver and the memory card shows up again.
Camera only Uninstall only the camera entry. Leave every other USB device alone.
