# v1.9.0 · R15NH 与 V8 原生部署

基于正式发行 v1.8.2，提交 `975f21e76c28ed82905438d35b4a86c1a49bf4b0`。保留原生 Windows 界面、USB 认证、驱动及分帧传输；本版不使用 WSL。

- 原创意外观 LUT 页更新为 R15NH，支持已识别的原厂、R8、R9、R9.1、R10、R11、R12。沿用 R12 的读取机身分区、识别版本、本地差分修补、写入流程；不分发 R15NH 完整分区镜像。写入使用 FF01 `/dev/nflasha15` 完整 300 MiB 通道。
- 新增 V8 悬浮菜单部署页。安装前重新校验 R15NH，先保存原入口和文件，最后切换预加载；载荷保持正式 V8 原字节。
- R15NH 支持同机完整分区、四配置和两张 LUT 配对回滚；V8 回滚恢复原预加载入口并保留载荷。V8 活动时阻断 R15NH 回滚。
- 软件内置部署与相机操作说明，保留原 Fn／PP、引闪、WiFi、4:3、官方回退入口。
- 两页顶部明确显示最近读取的机身状态、当前版本、载荷数量及预加载入口；不再只显示“读取完成”。
- 同时提供 227 个 A9P V2、23 组卡目录、离线色卡及照片推荐 16 槽。含基底与调色变体，常规近似和高误差实验项分列；来源许可与署名随包保留。

七套正式源镜像离线准备均得到固定 R15NH 目标，详见 `docs/r15nh-source-validation.json`。本安装器的最终离线测试、冻结自检及清单见交付验证报告；本版安装器尚待用户实机验收。既有 R15NH/V8 的实机记录不扩写为本安装器已验收。
