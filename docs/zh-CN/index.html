在 Sony A9 上开启 Picture Profile 和 SLog 显示辅助

适用机型：ILCE-9（第一代 A9），固件 6.00。整个过程大约 30 分钟，不需要装 Python，也不需要敲命令。

开始之前请先读完这段

  • 这个工具会修改相机里的功能参数，不是固件。改坏了可以用它自带的备份恢复。
  • 它只支持 ILCE-9 固件 6.00。其他机型、其他固件版本，程序会直接拒绝，不会写入任何东西。
  • 一共提供 77 个功能。其中 Picture Profile 和 SLog 显示辅助这两项在真机上验证过能用，其余 74 项从来没有人在真机上试过，包括可能出现相机卡死、必须拔电池的情况。
  • 已经知道「像素转换多重拍摄」会在拍第一张之后卡死，界面上把它标成了红色，但仍然可以点。
  • 风险自负。这不是索尼官方工具，出了问题索尼不会保修。

1. 开始之前

先确认三件事：

  1. 相机是 ILCE-9（机身背面写着 ILCE-9，不是 ILCE-9M2）。
  2. 固件版本是 6.00。在相机上查看：MENU → 设置 → 版本。
  3. 有一根能传数据的 USB 线，和一个能用的 Windows 10/11 电脑。
版本不是 6.00 怎么办？ 先不要用这个工具。不同固件版本里，参数存放的位置不一样，硬写进去可能损坏相机配置。程序会自己拦住，但请你也先确认一下。

你需要用到的两个网站，建议提前打开：

  • 本工具的下载页（GitHub Releases，链接在本页底部）
  • Zadig — 用来给相机装 USB 驱动的小工具，免费

2. 下载与解压

在 Releases 页面下载 ILCE-9_Slog_Project.exe，放到一个你找得到的地方，比如桌面。

这个程序没有安装过程，也没有卸载程序——它就是一个 exe 文件，双击就能用。第一次运行时，它会在自己所在的文件夹里建一个 sessions 文件夹，用来放每次修改前的备份。请不要删掉这个文件夹，恢复就靠它。

为什么它要建文件夹？ 因为每次改动相机之前，程序都会先把相机当时的完整参数存一份到这个文件夹里。万一改坏了，或者你反悔了，用它就能回到改之前。

3. Windows 拦住了这个程序

第一次双击时，Windows 很可能弹出一个蓝色窗口，写着「Windows 已保护你的电脑」。

点左边的 「更多信息」，然后点下面出现的 「仍要运行」。

原因很简单：这个程序没有买微软的数字签名证书（一年要几百美元，个人项目买不起）。Windows 见到没有签名的 exe 就一律拦下来，不代表它有问题。

4. 杀毒软件报毒

有些杀毒软件会把这个程序报成病毒。原因也一样：它需要直接读写 USB 设备，这个行为和某些恶意软件很像。

如果你不放心，可以看 GitHub 上的源代码——所有代码都公开，任何人都能检查它到底做了什么。不要从别的地方下载这个 exe。

5. 给相机装驱动（第一次）

这是整个流程里最容易卡住的一步，慢慢来。

5.1 让相机进入大容量存储模式

  1. 相机关机。
  2. 用 USB 线把相机连到电脑。
  3. 相机开机。
  4. 如果相机屏幕上问「USB 连接」，选 「大容量存储」（Mass Storage）。
  5. 这时电脑上会出现相机的存储卡。如果没有出现，换一根线或换一个 USB 口。

5.2 用 Zadig 换驱动

  1. 打开 Zadig（不需要安装，双击就行）。
  2. 点菜单 Options → List All Devices。
  3. 在中间的下拉列表里找到你的相机。它可能显示成 Sony Digital Still Camera 或者类似的名称。
  4. 确认右边显示的目标驱动是 libusb-win32。如果不是，点右边的箭头换成它。
  5. 点 Install Driver 或 Replace Driver，等它跑完。
不要选错设备 列表里可能还有一个叫 USB Input Device 之类、VID 是 054C、PID 是 0994 的设备。那个是相机的 USB 输入接口，不是这次要改的。改错了不影响相机，但电脑的输入设备会出问题。

5.3 装完之后，存储卡会消失

装完驱动后，你会发现 Windows 资源管理器里看不到相机的存储卡了，还可能弹出一个「需要格式化」的提示。

这是正常的，不是相机坏了。 新驱动把相机从「U 盘」变成了「一个程序可以直接对话的设备」，代价就是 Windows 不再把它当成 U 盘显示。不要点格式化。 用完工具之后按第 11 节把驱动换回去，存储卡就回来了。

6. 连接并检查

保持相机的「大容量存储」模式，双击打开 ILCE-9_Slog_Project.exe。

点 「① 连接并检查」 里的按钮。程序会做这几件事：读相机型号、读固件版本、确认是 6.00、把当前的全部参数备份一份、然后尝试把相机切换到服务模式。

中间可能需要几十秒，日志区会一行行往下滚。正常情况下你会看到：

  • 已确认 ILCE-9 / 6.00，正在切换服务模式
  • 服务模式已认证，正在读取机身参数
  • 然后「② 检测结果」里出现机型、固件、序列号指纹

7. 给相机装驱动（第二次）

如果第 6 步的最后卡住了，日志里出现 「Service device not found」 或者一段提到 Zadig 的提示，说明相机已经切到服务模式，但 Windows 还没给这个新出现的设备装驱动。

这是正常现象——服务模式是一个不同的 USB 设备，需要单独再装一次驱动。

  1. 相机不要拔线，保持现在的状态。
  2. 再打开一次 Zadig，Options → List All Devices。
  3. 这次会多出一个新的 Sony 设备，名字后面通常带 (Interface 1) 或者类似的标记。
  4. 同样给它装 libusb-win32。
  5. 回到本程序的窗口，点 「重试」。
重试按钮一小时后会失效 如果隔了太久才回来点重试，程序会提示你把相机拔掉重插、回到大容量存储模式重新开始。这一步不会写入任何东西，重来是安全的。

8. 开启 PP 放行，然后重启

连接成功之后，「② 检测结果」里会显示 PP 放行的状态。

如果是 「✗ 未开启」，点旁边的 「开启 PP 放行」。程序会改五个字节，然后自动保存。

为什么要重启相机？ 改完参数只是写进了相机的存储，相机要重新开机才会重新读取这些参数。程序会提示你关机重启，请照做。重启之前不要再做别的操作。

重启完之后，再打开本程序，重新走一遍第 6 步连接（第二次不需要再装驱动了）。

9. 把功能写进 Fn 槽位

「③ 选择功能」里默认显示两张卡片：

  • Picture Profile（图片配置文件）
  • SLog 显示辅助

每张卡片下面有一个槽位下拉框，选你想放进哪个 Fn 位置（Fn1 到 Fn12）。选好之后点「写入」。

如果要用的功能不在这两张卡片里，点下面的 「▸ 全部功能（77 项，多数未验证）」 展开完整列表，选一行，在弹出的框里选槽位，点「写入所选功能」。

写入成功后，整个窗口的写入按钮都会变灰。这是故意的：一次运行只做一次修改，每次修改都有自己的备份。要再改另一个槽位，关掉窗口重新打开。

10. 在相机上确认

写入完成后，程序会提示你关机重启。重启之后，在相机上按 Fn 键，看看对应的槽位有没有变成你写入的那个功能。

「菜单里出现了」不等于「功能能用」 这一步很重要。所有 12 个 Fn 槽位都能写进去，相机也会把它显示出来——但显示出来只说明入口存在，不代表功能真的能用。
  • Picture Profile 和 SLog 显示辅助：真机验证过能用，重启后依然有效。
  • 其余 74 项：从来没有人试过。可能出现灰显、点了没反应、甚至让相机卡死。
如果试了没反应，用第 11 节的方法恢复回去就好。

11. 改回去

11.1 撤销某一次修改

打开程序，连上相机，在「④ 恢复」的列表里会看到你之前做过的每一次修改，每条都标了时间和内容。

  1. 点选你要撤销的那一条。
  2. 点 「从备份恢复到原状」。
  3. 确认之后，程序会把那一次改过的值写回去，并自动保存。
  4. 关机重启相机。
连着改过好几次的话 每条记录的「原值」是指那一次修改之前的值。如果你先改了 Fn7、后来又改了 Fn12，那么撤销 Fn12 只会回到「Fn7 已经改过」的状态，不是出厂状态。列表的备注栏会提醒你这一点。

11.2 全部恢复到第一次使用之前

「④ 恢复」里的 「恢复全部原厂」 会把本工具改过的所有位置一次性写回第一次使用之前的值。

这个按钮会覆盖你手动改的东西 它会连你在相机上手动改过的设置一起覆盖掉。确认之前想清楚。

11.3 让 Windows 重新把相机当 U 盘

如果你不再需要用这个工具，可以按下面的步骤把驱动还原：

  1. 关掉本程序。
  2. 右键「开始」→ 设备管理器。
  3. 找到「libusb-win32 devices」或者其他的 Sony 相机条目。
  4. 右键 → 卸载设备，勾选 「删除此设备的驱动程序软件」。
  5. 拔掉 USB 线，重新插上。
  6. Windows 会自动装回原来的驱动，存储卡又能看到了。
只针对相机 卸载的时候看清楚，只卸相机那一条，不要动别的 USB 设备。
